# **19.11 Summary and Exam Checklist**

## **Key Definitions**

| Term | Meaning |
| ---- | ------- |
| photon | a quantum of electromagnetic radiation |
| threshold frequency | minimum frequency required for photoemission from a metal |
| de Broglie wavelength | wavelength associated with a particle, $\lambda = \frac{h}{p}$ |
| wavefunction | mathematical description of a particle's quantum state |
| probability density | $\lvert \psi \rvert^2$, probability per unit length in one dimension |
| normalisation | choosing constants so total probability is 1 |
| superposition | addition of wavefunctions to give a resultant wavefunction |
| infinite square well | model where a particle is confined between impenetrable walls |
| line spectrum | spectrum containing discrete wavelengths from energy level transitions |

## **Key Equations**

| Equation | Meaning |
| -------- | ------- |
| $E = hf$ | photon energy |
| $E = \frac{hc}{\lambda}$ | photon energy from wavelength |
| $p = \frac{E}{c}$ | photon momentum |
| $p = \frac{h}{\lambda}$ | photon momentum from wavelength |
| $\lambda = \frac{h}{p}$ | de Broglie wavelength |
| $\int \lvert \psi \rvert^2 dx = 1$ | normalisation |
| $\psi_n(x)=\sqrt{\frac{2}{L}}\sin\left(\frac{n\pi x}{L}\right)$ | normalised particle-in-a-box wavefunction |
| $L = \frac{n\lambda}{2}$ | allowed wavelengths in a box |
| $E_n = \frac{h^2n^2}{8mL^2}$ | allowed energies in a box |
| $\Delta x \Delta p \gtrsim h$ | uncertainty estimate |
| $hf = \Delta E$ | atomic transition photon energy |

## **Concept Map**

```text
photoelectric effect -> photons -> E = hf -> threshold frequency

interference and diffraction -> wave model of light

electron diffraction and single-particle interference -> matter waves
matter waves -> de Broglie wavelength -> lambda = h / p

wavefunction psi -> probability density |psi|^2 -> normalisation
superposition -> interference and standing waves
standing waves in a box -> allowed wavelengths -> quantised energies

discrete atomic energy levels -> photon transitions -> line spectra
```

## **Common Exam Question Types**

- Explain why threshold frequency supports the photon model.
- Calculate photon energy or momentum from frequency or wavelength.
- Calculate de Broglie wavelength for an electron or other particle.
- Interpret a $\psi$ or $\lvert \psi \rvert^2$ graph.
- Find normalisation constants for square or sinusoidal wavefunctions.
- Use $E_n = \frac{h^2n^2}{8mL^2}$ for a particle in a box.
- Estimate uncertainty in momentum from a given position uncertainty.
- Find the wavelength of a photon emitted or absorbed in an atomic transition.
- Compare emission and absorption line spectra.

## **Common Mistakes**

- Saying intensity can overcome a frequency below threshold.
- Forgetting to convert nm to m.
- Treating $\psi$ as probability instead of $\lvert \psi \rvert^2$.
- Normalising with $\int \psi dx$ instead of $\int \lvert \psi \rvert^2 dx$.
- Allowing $n=0$ for a particle in a box.
- Using the wrong mass in $E_n = \frac{h^2n^2}{8mL^2}$.
- Forgetting that absorption is upward and emission is downward.
- Using signed energy levels incorrectly; photon energy is the magnitude of the energy difference.

!!! warning "Common misconception"
    Quantum answers need evidence and equations. A vague phrase like "wave-particle duality" is not enough unless it is linked to a specific observation such as threshold frequency, interference, diffraction or single-particle build-up.
